# crawl.md — прогулка по сайтам компании → конструктор страниц + TOV

Цель: до того как писать, агент изучает существующие сайты компании ученика (WebFetch),
чтобы (а) вытянуть голос/TOV, (б) понять, какие типы страниц нужны бизнесу.

```
Изучи сайт(ы) компании: {URL1, URL2, …}. Через WebFetch пройди по ключевым страницам
(главная, услуги/товары, о компании, блог если есть, контакты).

Верни:
1. TONE OF VOICE: как компания говорит (на «ты»/«вы», тон, характерные фразы, что НЕ говорит).
   → заполни черновик company_voice.md.
2. ЧТО ПРОДАЮТ: продукты/услуги, чем отличаются, гео.
3. КОНСТРУКТОР СТРАНИЦ: какие типы страниц нужны этому бизнесу и почему. Например:
   - статья (блог) — под информационные запросы;
   - страница услуги — под коммерческие запросы;
   - гео-страница (услуга × район/город) — длинный хвост;
   - кейс/портфолио — доверие.
   Для каждого типа: какой запрос закрывает, какая структура.
4. ЧЕГО НЕ ХВАТАЕТ: какие типы страниц/темы у конкурентов есть, а тут нет.
```

Результат — основа для движка тем (`topics.md`) и конструктора страниц. Голос → `company_voice.md`.
