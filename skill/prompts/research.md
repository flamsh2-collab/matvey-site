# research.md — этап 1 (Perplexity через OpenRouter)

Веб-research для фактуры статьи. Провайдер — Perplexity в OpenRouter
(`PERPLEXITY_MODEL`, по умолч. `perplexity/sonar-pro-search`; запасной `perplexity/sonar-pro`).
Вызов — OpenRouter `chat/completions`. Дёшево/быстро — дополняем `WebFetch` сайтов напрямую.

```
Собери фактуру для статьи по теме «{ТЕМА}».
Ниша: {company_voice: ниша}. Аудитория: {company_voice: клиент}. Гео: {если важно}.

Верни:
1. 5–8 фактов/цифр с источниками (свежие, ≤1–2 года).
2. 3–5 вопросов, как их задаёт аудитория (для FAQ и H2).
3. Что упускают конкуренты по теме.
4. 3–5 смежных тем для перелинковки.
5. Гео-привязка (если бизнес локальный): город/район/метро/локальные ключи.

Тезисно, со ссылками. Без воды.
```

Если ключа OpenRouter нет — пиши из контекста компании + WebFetch; статьи слабее по свежим фактам.
GATE: ≥5 фактов с источниками + ≥3 вопроса аудитории.
