# write.md — этап 2

```
Напиши SEO-статью по теме «{ТЕМА}» на основе фактуры из research.
Голос — строго из company_voice.md (тон, лексика, стоп-слова).

Структура:
- H1 — с ключевым запросом, по-человечески.
- TLDR (первые 150–200 слов) — короткий прямой ответ на запрос. Это для поиска и для ИИ-поисковиков.
- 4–7 секций H2 (по вопросам аудитории), где нужно — H3.
- Конкретика: цифры, примеры, шаги. Без «воды о современном мире».
- FAQ — ≥3 вопроса прямыми формулировками + ответы.
- Финал: ≥2 CTA (мягких, под бизнес).

Объём: 1500–2500 слов. Голосом компании, не «блоговым» дефолтом.

ФАКТУРА:
{вывод research}
```

GATE: ≥1500 слов · H1×1 · H2/H3 ≥5 · FAQ ≥3 · CTA ≥2 · TLDR в первых 200 словах.
