# cluster.md — кластер статей (масштаб)

```
По теме-флагману «{PILLAR}» предложи контент-кластер:
- 1 pillar-статья (широкая, обзорная).
- 8–15 подстатей под узкие запросы.
- для каждой: рабочий заголовок + основной запрос + 1 строка о чём.

Схема перелинковки: каждая подстатья ↔ pillar + смежные подстатьи.
Для гео-бизнеса — добавь срез по локациям (район/метро/город).
Отметь темы, которые можно взять из расшифровок М4/М5.
Заполни content_plan.html со статусами «в работу».
```

Дальше — гонишь кластер пачкой через 7 этапов (по статье за проход), скилл сам ставит внутренние ссылки.
