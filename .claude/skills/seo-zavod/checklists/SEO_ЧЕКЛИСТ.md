# SEO-чек-лист (этап 4) · GATE

> Зелёный чек-лист = статья готова к деплою. Основано на требованиях pleada.shop.

## Структура
- [ ] H1 — один, с ключевым запросом, по-человечески (не «всё о…»).
- [ ] H2/H3 — ≥5 секций, по вопросам аудитории из research.
- [ ] FAQ — ≥3 вопроса прямыми формулировками (как ищут люди).
- [ ] CTA — ≥2 (мягкий, под бизнес).
- [ ] Объём — ≥1500 слов (целевой 1500–2500).
- [ ] TLDR — короткий ответ на запрос в первых 200 словах.

## Мета и адрес
- [ ] title ≤60 символов, с ключом.
- [ ] description 140–160 символов, цепляет в выдаче.
- [ ] slug латиницей, через дефис, уникален (проверка по `SITE_MAP.md`).

## Связность
- [ ] 2–5 внутренних ссылок на смежные статьи (перелинковка), естественно в тексте.
- [ ] Хотя бы 1 внешний авторитетный источник (если уместно).

## Картинки
- [ ] heroImage задан, URL живой (HTTP 200), не дубль с другой статьи.
- [ ] ≥2 inline-картинки в теле как `![alt](url)` с осмысленным alt.

## Schema (JSON-LD) + GEO
- [ ] Article + FAQPage + BreadcrumbList.
- [ ] Для товаров/услуг — Product / Service; недвижимость — RealEstateListing; локальный бизнес — LocalBusiness.
- [ ] `public/llms.txt` пополнен (кураторский индекс для ИИ-поисковиков).
- [ ] sitemap.xml и RSS отдаются (интеграции `@astrojs/sitemap`, `@astrojs/rss`).

## Ключи
- [ ] Основной ключ в title + H1 + первом абзаце + хотя бы одном H2.
- [ ] Без переспама (ключ органично, не «купить квартиру спб купить квартиру спб»).
