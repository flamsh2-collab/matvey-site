# Скилл «SEO-завод» (база · Cursor)

Учим **механике автосоздания страниц на сайте**: запускаешь — страницы создаются и уходят на сайт сами. Построено на реальном движке pleada.shop (64 000 страниц + ~1500 статей).

## Принцип
**Качество держит пайплайн, а не дорогая модель.** Дешёвая потоковая модель + сильная обвязка (research → гуманайзер → SEO → гео/GEO → проверки) бьёт дорогую модель без обвязки.

## Стек и доступы
- **Astro** — статический сайт. Агенту подключён **Astro Docs MCP** (`mcp.docs.astro.build`) — он по актуальной доке грамотно скаффолдит сайт/блог через `npm create astro`, content collections, `[slug].astro`, `getStaticPaths`.
- **Research:** Perplexity через OpenRouter (`PERPLEXITY_MODEL`, по умолч. `perplexity/sonar-pro-search`).
- Голос: `company_voice.md`. План тем: `content_plan.html`. Статьи: `src/content/blog/`. Антидубль: `SITE_MAP.md`. Ключи: `.env`.
- Чек-листы: `checklists/`. Промпты: `prompts/`. Метод тем: `../../ДВИЖОК_ТЕМ.md`.

## Что делает скилл (5 способностей)

### 1. Поднять сайт + минимальный блог (через Astro MCP)
По запросу «подними сайт/блог» — по Astro Docs MCP скаффолдит минимальный Astro-блог: content collection `blog`, роут `[slug].astro`, `@astrojs/sitemap` + `@astrojs/rss`, `public/llms.txt`. Если у ученика уже есть сайт — работает в его репозитории.

### 2. Прогулка по сайтам компании → конструктор страниц + TOV
По запросу «изучи мой сайт» — `WebFetch` по страницам сайта(ов) ученика: вытягивает голос/TOV, продукты, типы страниц → предлагает **конструктор страниц под бизнес** (какие типы страниц нужны: статья, услуга, гео-страница, кейс) и заполняет черновик `company_voice.md`.

### 3. Движок тем: первые 10 → длинный хвост
По запросу «собери темы» — по методу `../../ДВИЖОК_ТЕМ.md`: берёт выгрузки ученика (Wordstat CSV, топ-страницы Metrika, вопросы из звонков М5, JTBD) → приоритизирует первые 10 → разворачивает в хвост (кластеры + модификаторы + программный слой) → пишет в `content_plan.html`.

### 4. Написать статьи по запросу (7 этапов с GATE)
По запросу «напиши N статей по плану и задеплой» — для каждой темы проходит 7 этапов ниже.

### 5. Программный слой (длинный хвост из данных)
По запросу «сделай страницы услуга×район» — из таблицы `src/data/*.json` через `getStaticPaths` генерирует страницы под каждую комбинацию (десятки/сотни страниц одним билдом). См. `prompts/programmatic.md`.

---

## 7 этапов с GATE (для каждой статьи)
> GATE = жёсткая проверка. Не прошёл — чинишь, не идёшь дальше.

1. **ИССЛЕДОВАНИЕ** — `prompts/research.md` (Perplexity через OpenRouter + WebFetch). GATE: ≥5 фактов с источниками + ≥3 вопроса аудитории.
2. **НАПИСАНИЕ** — `prompts/write.md`. GATE: ≥1500 слов · H1×1 · H2/H3 ≥5 · FAQ ≥3 · CTA ≥2 · TLDR в первых 200 словах.
3. **ГУМАНАЙЗЕР** — `prompts/humanize.md` + `checklists/HUMANIZER_БАНЫ.md`. GATE: 0 HARD BANS · 0 стоп-слов.
4. **SEO** — `prompts/seo.md` + `checklists/SEO_ЧЕКЛИСТ.md`. GATE: чек-лист зелёный, JSON-LD валиден.
5. **ГЕО / GEO** — `prompts/geo.md`. GATE: TLDR отвечает на запрос; для локального бизнеса — гео-ключ в title/H1; запись в `llms.txt`.
6. **АНТИДУБЛЬ + ВЁРСТКА** — проверка `SITE_MAP.md`; файл в `src/content/blog/<slug>.md`; hero обязателен, картинки 200.
7. **ДЕПЛОЙ + ИНДЕКСАЦИЯ** — `deploy.md` (build → push → автодеплой → проверка 200 → sitemap/llms.txt → опц. Я.Вебмастер). Обновить `SITE_MAP.md` и `content_plan.html`.

> ⚙️ Тумблер `REVIEW_BEFORE_PUBLISH=true` в `.env` → показать черновики и ждать «ок» (принцип «тренируй на себе»).

## Режимы
- **Пачка:** N статей за запуск из `content_plan.html`.
- **Кластер** — `prompts/cluster.md`: pillar + подстатьи, перелинковка.
- **Программные страницы** — `prompts/programmatic.md`: данные → getStaticPaths.
- **Пост на событие:** одно событие → один пост голосом компании.
- **Rewrite:** обновить статью (цены/факты), URL сохранить.

## Модель
Поток — дешёвая модель (Gemini Flash Lite ≈ $0,002/статья). Премиум-темы — Sonnet/Opus. В Cursor — выбор в UI; `OPENROUTER_API_KEY` — для batch/пресета. Подробно — `../../ВЫБОР_МОДЕЛИ.md`.
